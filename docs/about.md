# GPokeT2 — Pokémon Sprite Generator

![GPokeT2](gpoket2.png)

A **GPT-2 based autoregressive model** that generates 64×64 Pokémon sprites token by token,
conditioned on type, generation, evolution stage and more.

## What is GPokeT2?

GPokeT2 is an autoregressive image generation model that treats each Pokémon sprite as a sequence
of pixel tokens. Instead of diffusion or GAN approaches, it uses a GPT-2 architecture to predict
the next pixel given all previous pixels — conditioned on Pokémon metadata such as type, generation,
and evolution stage.
